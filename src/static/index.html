What it is

remo turns any VPS into a personal PaaS. You git push, your app is live at {you}-{app}.remoapps.site. That's it.


⚡
Instant deploys git push → live in under 5 seconds

Custom domains Point any domain, TLS auto-provisioned
🔑
SSH key auth No passwords, no dashboard login

How it works

  1. Install the CLI Download and login once:

    curl -fsSL https://remoapps.site/install.sh | sh
    remo login --server https://remoapps.site --token <your-token>
  2. Create an app remo app create myapp
    Gets you you-myapp.remoapps.site instantly.
  3. Add the remote and push 
    git remote add remo git@remoapps.site:myapp
git push remo main
  4. Done Your app is live. Every subsequent git push deploys atomically — zero downtime, rollback in one command.

Deploy workflow

# push deploys automatically
git push remo main
  ↓ git archive
  ↓ extract → deploys/<sha>/
  ↓ symlink swap: current/ → deploys/<sha>/
  ↓ nano-rs reload
Deployed myapp @ a1b2c3d4

# instant rollback
remo rollback myapp

# live runtime stats
remo logs myapp --follow

Self-host remo

remo is open source. Run it on your own VPS in minutes.

# on your VPS (as root)
wget -qO /usr/local/bin/remo \
  https://github.com/gleicon/remo/releases/latest/download/remo-linux-amd64
chmod +x /usr/local/bin/remo
remo server install --domain apps.yourdomain.tld

→ github.com/gleicon/remo
